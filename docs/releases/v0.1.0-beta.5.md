# pack-preflight v0.1.0 beta 5

Production-awareness beta for external print and prepress testing.

## New since beta 4

- effective raster-image resolution diagnostics based on placed size, with a 350 dpi default threshold
- configurable image-resolution threshold with `--min-image-dpi`
- used-content RGB diagnostics that distinguish raster images, vector artwork, and text
- DeviceRGB, CalRGB, and ICCBased RGB recognition
- mixed RGB/CMYK page warnings for separation review
- unused RGB resource entries no longer trigger the same warning as actually painted RGB content
- production knowledge model documenting how field experience is converted into software rules, operator messages, and regression tests

## Existing workflow features

- inspect one or many PDFs
- scan job folders, optionally recursively
- combined batch HTML dashboards
- JSON output
- minimum bleed and page-box diagnostics
- font embedding and spot-color reporting
- PDF/X-related metadata and OutputIntent reporting
- encrypted/unreadable PDF handling
- exact build identification with `--version`

## Beta limitations

This is an early beta. The standalone executables are unsigned and not notarized, so macOS or Windows may show a security warning.

RGB and effective-resolution findings are production-risk diagnostics. They do not predict a RIP's final separation or claim that a file will necessarily print incorrectly.

The project does not certify PDF/X, ISO, Ghent Workgroup, food-contact, or regulatory compliance. A PASS only means that a file passed the checks implemented in this beta.

Please use non-confidential test files where possible and report false positives, missed risks, crashes, and disagreements with established preflight tools.
