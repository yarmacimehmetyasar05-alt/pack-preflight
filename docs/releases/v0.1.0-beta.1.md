# pack-preflight v0.1.0 beta 1

First public beta build for real print and packaging preflight testing.

## Included

- minimum bleed checks around TrimBox
- explicit TrimBox / BleedBox diagnostics
- per-page trim dimensions
- inconsistent page-size detection
- basic font-embedding checks
- RGB resource detection
- spot-color reporting
- PDF/X-related metadata reporting
- OutputIntent reporting
- terminal, JSON, and standalone HTML reports
- macOS, Windows, and Linux standalone beta archives

## Beta limitations

This is an early beta. The standalone executables are currently unsigned and not notarized, so macOS or Windows may show a security warning.

The project does not certify PDF/X, ISO, Ghent Workgroup, food-contact, or regulatory compliance. A PASS only means that a file passed the checks implemented in this beta.

Please use non-confidential test files where possible and report false positives, missed risks, crashes, and disagreements with established preflight tools.
